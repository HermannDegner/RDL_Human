# RDLによる言語・共有文脈・言語変化の関係モデル

*T2応用候補 / LANGUAGE / DRAFT v0.1*
*依存：T0 基底仮設（HYP） / T0 最低動作仕様（SPEC）*

---

## 0. 本文書の目的

本稿は、言語を単なる語彙・音声・文法規則の集合としてではなく、

> **有限境界 `B` の内部で、複数の `M_B` が、明示情報と非明示情報を利用しながら相互に更新される関係構造**

として記述するための暫定モデルである。

特に以下を扱う。

* 主語・目的語などの省略
* 共有文脈
* 「空気」と呼ばれる暗黙状態
* 言語ごとの明示性の差
* 環境による言語変化
* 言語習得
* 言語と制度・共同体の関係

本稿では、言語に固有の新たな基底実体を設定しない。

言語現象はすべて、T0の

`B / ξ / M_B / SILN / EFP / F / E / H / θ`

によって有限的に切り出して扱う。

---

# 1. 言語の基本位置づけ

言語を、

> **意味を完全に内包した記号列**

とは定義しない。

実際の言語運用では、発話として明示されない情報が大量に利用される。

たとえば、

> 食べた？

という発話には、

* 誰が
* 何を
* いつ
* 何について
* どの状況で

といった情報が明示されていない場合がある。

それでも通信が成立するなら、必要な構造の一部が発話外部から供給されている。

したがってRDLでは、言語事象を暫定的に、

```text
Language_B
=
明示されたSILN
+
文脈として参照されるSILN
+
それらを解釈するM_B
+
ξ
```

として扱う。

ここで `+` は単純な集合和を意味しない。

実際の接続形式は対象ごとに異なるため、必要に応じてT1操作で具体化する。

---

# 2. 明示情報と文脈情報

言語通信において、少なくとも二種類の有限構造を区別できる。

```text
SILN_exp
:= 発話・文字・身振りなどとして明示された構造

SILN_ctx
:= 発話時に参照可能な環境・履歴・関係・制度などの構造
```

ただし、`SILN_ctx` が話者間で完全に同一であるとは仮設しない。

話者Aと話者Bは、それぞれ異なる `M_B` を持つ。

したがって、

```text
M_B^A(SILN_ctx) ≠ M_B^B(SILN_ctx)
```

でありうる。

共有文脈とは、

> **同一の情報が完全に共有されている状態**

ではなく、

> **異なる `M_B` 間でも、通信を維持できる程度に近い解釈を生成する文脈構造**

として扱う。

常に `ξ` が残るため、完全な共有状態は要求しない。

---

# 3. 言語通信の最低フロー

言語入力も、通常のRDL入力と同様に扱う。

```text
EFP_lang
   ↓ M_Bによる解釈
F_lang
   ↓ 既存構造との差異
E_lang
   ↓ 残存・蓄積
H_lang
   ↓ θ_lang
維持 / 局所更新 / 再編
   ↓
M_B'
```

`EFP_lang` には、音声や文字だけでなく、その時点で作用している環境情報を含めてよい。

例：

```text
EFP_lang
=
{
  発話,
  視覚情報,
  身振り,
  相手,
  場所,
  社会的役割,
  過去の会話履歴,
  制度,
  行動結果,
  その他ξ
}
```

したがって、語彙と文法だけを取り出したものは、言語現象全体の一つの有限切り出しにすぎない。

---

# 4. 非明示は欠損ではない

RDLでは、省略を原理的に「情報欠損」とは扱わない。

必要な情報が `SILN_exp` に存在しなくても、

```text
M_B
+
SILN_exp
+
SILN_ctx
→
F_lang
```

として十分な解釈が成立するなら、通信上の問題は発生しない。

したがって、

```text
非明示 ≠ 情報不存在
```

である。

より正確には、

```text
非明示
=
情報の取得先をSILN_exp以外へ置く運用
```

とみなせる。

この意味で、

> **明示化されないものも言語運用の一部である。**

---

# 5. 共有文脈

共有文脈は、単一種類ではない。

少なくとも以下を区別できる。

### 5.1 即時共有文脈

その場で観測可能なもの。

```text
場所
人
物体
直前の発話
現在の出来事
```

### 5.2 関係共有文脈

反復的な人間関係から形成されるもの。

```text
家族
友人
職場
役割
序列
過去の共同経験
```

### 5.3 制度的共有文脈

制度によって反復的に供給されるもの。

```text
文字
法律
行政制度
教育
宗教
儀礼
職位
暦
標準語
```

### 5.4 予測共有文脈

現在状態から共同体内で比較的安定して生成される予測。

```text
季節変化
天候
動物行動
仕事の手順
社会的応答
今後予想される展開
```

したがって共有文脈は、

> 過去に共有された情報

だけではない。

現在環境および、そこから生成される近未来予測も共有文脈になりうる。

# 6. 「空気」の暫定的位置づけ

日本語で「空気」と呼ばれるものは、RDL上では独立した実体として置かない。

暫定的には、

> **ある `B` 内で複数の `M_B` が共有可能だと推定している、非明示の関係構造群**

として切り出せる。

```text
SILN_air
⊂
SILN_ctx
```

その内容には、

```text
期待される役割
発言可能範囲
感情状態
序列
禁忌
既知事項
予測される応答
```

などが含まれうる。

「空気を読む」とは、

```text
SILN_exp
+
非言語EFP
+
既存M_B
→
SILN_air の局所推定
```

と記述できる。

ただし推定された `SILN_air` にも `ξ` が残る。

したがって「空気」は常に誤読可能である。

# 7. 明示化圧

ある情報 `x` を発話内で明示する必要性は、固定値ではない。

暫定的に、

```text
ExplicitPressure_B(x)
```

を、

> **その情報を非明示化した状態が、現在の環境でどれだけ維持困難になるか**

を示す補助量として導入できる。

これはCore Primitiveではない。

標準的な評価要因として、

```text
ExplicitPressure_B(x)
≈
f(
  使用頻度,
  誤認発生率,
  誤認結果の重大性,
  共有文脈からの復元可能性,
  学習コスト,
  修復コスト,
  既存使用頻度,
  ξ
)
```

を考えられる。

特に、

```text
誤認が頻繁
かつ
結果が重大
かつ
文脈から復元しにくい
```

情報ほど、明示化圧が高くなると仮設できる。

逆に、

```text
文脈からほぼ確実に復元できる
かつ
誤認しても修復が容易
```

なら、非明示運用が維持されうる。

# 8. 生存・維持結果

ここでいう「結果」は、生物学的生存だけに限定しない。

対象 `B` に応じて、

```text
身体的生存
食料獲得
危険回避
取引成功
社会関係維持
制度維持
作業効率
誤解回避
学習効率
```

などを設定できる。

したがって、

> 「何を明示する言語が優れているか」

という絶対評価は行わない。

評価可能なのは、

> **ある環境 `B` において、ある言語運用がどのような結果を反復的に生成したか**

である。

---

# 9. 「みんなが使っている」は環境である

言語では、既存の使用状態そのものが次の使用者に対する環境になる。

ある表現 `u` が多数によって使用されているなら、

```text
Use(u,t)
→
EFP_lang(t+1)
```

となる。

つまり、

```text
過去の使用結果
→
現在の言語環境
→
次の使用
```

という循環が成立する。

このため、表現の残存性は単純な効率だけでは決まらない。

多少不規則でも、

```text
多数が使用
→
学習される
→
理解される
→
さらに使用される
```

という経路が成立すれば維持される。

逆に、多数が使用していても、

```text
高頻度の誤認
→
修復コスト
→
H_lang蓄積
→
別表現への局所更新
```

が繰り返されれば、別の運用が優勢になる可能性がある。

---

# 10. 言語変化

言語変化は、目的を持った最適化として扱わない。

暫定的には、

```text
変異
→
使用
→
環境との相互作用
→
結果
→
使用頻度の偏り
→
次の環境
```

として扱う。

RDL表記では、

```text
M_B(lang,t)
   ↓ EFP
複数の表現変異
   ↓
使用結果
   ↓
E
   ↓
H
   ↓ θ
維持 / 更新 / 再編
   ↓
M_B(lang,t+1)
```

となる。

ここでは、

> **結果が次の環境になる。**

したがって言語の現在構造には、それ以前の使用履歴が整合慣性として残る。

---

# 11. 言語多様性

言語が多様であることは、このモデルでは例外ではない。

異なる共同体では、

```text
B
EFP
M_B
共有文脈
誤認結果
使用履歴
制度
他言語接触
```

が異なる。

したがって、同じ人類が使用していても、

```text
B₁ → M_B(lang₁)

B₂ → M_B(lang₂)

B₃ → M_B(lang₃)
```

という複数の安定構造が成立しうる。

よって、

> **単一の理想言語へ収束しないこと自体が自然である。**

生物が異なる環境で異なる構造を残すように、言語も異なる関係環境の中で異なる構造を残す。

# 12. 日本語・英語・中国語の暫定比較

以下は確定的起源説明ではなく、本モデルを用いた比較仮説である。

## 12.1 日本語

日本語では、主体・対象などを `SILN_exp` に明示しなくても、

```text
SILN_ctx
+
M_B
```

から復元可能な状況が多い。

したがって、

```text
ExplicitPressure_B(主体)
```

が比較的低い環境が長期間維持された可能性を考えられる。

地理的境界、反復的共同体、制度、役割関係などは、その環境条件候補である。

---

## 12.2 中国語圏

中国語圏では口頭言語の地域差が大きい一方、

```text
文字
行政
教育
古典
国家制度
```

などによる制度的共有文脈が長期に形成されてきた。

したがって、

> 口語が均一であること

と、

> 広域の共有文脈が存在すること

は同一ではない。

制度が `SILN_ctx` の一部を広域に供給することが可能である。

---

## 12.3 英語

英語史では、異なる言語・方言・社会背景を持つ話者との接触が繰り返されている。

そのような環境では、

```text
M_B^A(SILN_ctx)
```

と

```text
M_B^B(SILN_ctx)
```

の差が大きくなりやすい。

結果として、主体・対象・関係などについて、

```text
ExplicitPressure_B(x)
```

が高くなる状況が反復した可能性を検討できる。

ただし、これを英語の構造を単独で決定した原因とはしない。

---

# 13. ピダハン語への暫定適用

ピダハン語については、直接経験性を重視する文化・言語記述が提示されているが、その強い因果解釈には異論がある。

RDLでは、

> 「未来を理解できない」
> 「抽象概念を持たない」

といった能力欠如を前提に置く必要はない。

代わりに、

```text
現在の観測
+
共有された環境モデル
→
近未来予測
```

が十分に機能する環境なら、

> 未来を詳細に外在化する必要性が低い

という関係仮説を置くことができる。

重要なのは、

```text
何を考えられるか
```

ではなく、

```text
何を明示しなくても結果が安定するか
```

である。

---

# 14. 言語習得

言語習得も語彙・文法のみの取得とは扱わない。

学習者が受ける入力は、

```text
EFP_lang
=
発話
+
場面
+
人間関係
+
反応
+
結果
+
制度
+
非言語情報
+
ξ
```

である。

学習者の `M_B` は、

```text
EFP_lang
→
F
→
E
→
H
→
Update(M_B)
```

を反復することで更新される。

その結果として学習されるのは、

* 何を言うか
* 何を言わないか
* 何を共有済みとみなすか
* 誰に何を明示するか
* どの程度の曖昧さが許容されるか
* どの発話がどの結果を生むか

まで含む。

したがって、完全な言語習得に近づくほど、

> **その言語が使用される環境モデルの一部を取得する**

ことになる。

---

# 15. 言語と世界モデル

異なる言語を使用すると、同一人物でも異なる `M_B` が活性化・更新されうる。

ただし、

> 言語が人格そのものを直接変更する

とは仮設しない。

より限定的には、

```text
M_B
+
Language_B1
→
Response_1

M_B
+
Language_B2
→
Response_2
```

のように、異なる言語環境によって異なる局所構造・注意配分・応答経路が活性化すると扱う。

これは、

```text
家庭
職場
友人集団
```

などで異なる応答モデルが起動することと連続的に扱える。

したがって言語切替は、

> **比較的大きな環境境界 `ΔB` に伴う `M_B` の局所的再編**

として読むことができる。

---

# 16. 最小モデル

本稿の議論は、最小限には次の形へ圧縮できる。

```text
Environment_B
      ↓
EFP_lang
      ↓
M_Bによる解釈
      ↓
F_lang
      ↓
E_lang
      ↓
H_lang
      ↓ θ
維持 / 更新 / 再編
      ↓
M_B'
      ↓
次のEnvironment_B
```

言語共同体全体では、

```text
使用
→
結果
→
残存
→
共有化
→
環境化
→
次の使用
```

となる。

---

# 17. 圧縮定義

> **RDLにおける言語とは、有限境界 `B` のもとで、複数の `M_B` が、明示された記号構造と非明示の文脈構造を利用して相互作用し、その結果によって維持・更新・再編され続ける関係構造である。**

言語において、

> **明示されないことは、必ずしも情報が存在しないことを意味しない。**

情報が環境・制度・関係・履歴・予測などから安定して回収可能であれば、それらを明示しない運用も維持されうる。

逆に、非明示化が反復的に重大な差異 `E` と蓄積 `H` を生むなら、明示化・別表現・制度化などへの更新圧が生じうる。

したがって、言語の構造は固定された理想形ではなく、

> **過去の使用結果が次の環境となり、その環境下でさらに更新され続けた有限構造**

として扱う。

そしてその構造にも常に `ξ` が残る。
