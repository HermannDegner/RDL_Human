## 1. 目的と認識論的位置づけ（便宜的ツールとしての4層）

本文書は、人間（および基層構造を持つ生体・自律エージェント）の整合構造 $M_B$ を、**変化の時間スケール（安定度）の差異**によって4つの階層に分解・モデル化する。

:::message
**【重要：真理ではなく「便宜上の操作ツール」】**  
本4層構造は、世界や人間の絶対的真理として実体化されたものではない。連続的で複雑な生体・心理動態を、有限な認識系が扱いやすく記述・操作するための**「便宜上の境界設定（境界 $B$ / 便利ツール）」**である。  
したがって、層と層の境界には常に**回収されない関係（未回収関係 $\xi$）**が残存し、必要に応じて境界の引き直しや再編（Leap）が行われることを前提とする。
:::

## 2. 4層の基本定義

整合構造 $M_B$ は、時間スケールの遅い（超安定）層から速い（可変）層へ向かって、便宜上次の4層として切り出される。

```text
物理構造  ＞  基層構造  ＞  中核構造  ＞  上層構造
←── 安定・低速（長期的制約） ─────────── 不不安定・高速（即時適応） ──→
```

## 3. 双方向の層間相互作用力学（T2耐久検査知見）

4層は一方通行の階層ではなく、**激しい上下双方向の相互作用系（Reciprocal Coupling）**である。

### 3.1 ボトムアップ制約（下層 $\to$ 上層）
- **下層は上層の可能域を決定する**: 物理構造（第1層）や基層構造（第2層）に反する上層構造（第4層）は維持できない（例：睡眠不足・低血糖・極度の疲労では、信念や思考は強制停止する）。
- **基層パラメータによる中核のバイアス**: 基層の `Explore` や `Stabilize` の初期設定が、その個体がどのような中核信念を好んで採用・定着させるかを方向づける。

### 3.2 トップダウン逆流と極限破壊（上層 $\to$ 下層）
- **遠距離予測による未来熱の逆流（絶望と心身症）**:
  - 人間特有の遠距離予測（$R(d_{\text{far}})$）により、「未来が苦痛・破滅だらけである」と外挿されると、物理層が無傷であっても**莫大な未来予測熱 $H_{\text{future}}$ が現在に逆流**する。
  - この熱が基層の `Alert`（NA/コルチゾール）を過覚醒させ、物理層の血管収縮・胃腸障害・筋緊張という「現実の肉体的苦痛」を実体化させる。
- **自己境界拡張による下層の消費（殉教・自己犠牲）**:
  - 強い `Affiliate`（オキシトシン的結合）により自己境界 $B_{\text{self}}$ が神・国家・子孫・集団へと拡大すると、「守るべき第1層」が集団の存続へとスライドする。
  - その結果、集団の存続のために個体肉体を消耗品として消費する**「殉教・特攻・利他自死」**が実行される。
- **社会的シグナルによる閾値変調（模倣・ウェルテル効果）**:
  - 他者の自死や行動が報道・観測されると、認知空間上の流路抵抗が下がり、実効閾値 $\theta_{\text{eff}}$ が低下するため、高熱 $H$ を抱えた別個体の相転移（連鎖）が誘発される。

## 4. 破断条件と修復優先順位

各層が過負荷によって破断した場合の挙動と介入順位：

```text
物理構造の破断 ──→ 生命維持の危機（全層の強制停止）
基層構造の破断 ──→ 神経・情動機能の破綻（パニック、過覚醒、無気力）
中核構造の破断 ──→ アイデンティティクライシス（信念崩壊、価値観の喪失）
上層構造の破断 ──→ 一時的な混乱・日常的フラストレーション（局所的放熱で修復可能）
```

:::message
**【介入の設計原則】**  
上層の暴走（予期不安・パニック）に対して上層の処理（議論・説得）だけで止めようとしてはならない。  
物理層の強制弛緩（深呼吸・横になる・睡眠） $\to$ 基層の警戒 Alert 沈静化 $\to$ 中核・上層のシミュレーション停止、というように**下層からの物理的遮断と放熱を併用する**ことが極めて有効となる。
:::
