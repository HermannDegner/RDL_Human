## ■ 0. 一文定義

> **基層構造（第2層）は、物理的制約のもとで個体の反応特性・熱発生係数・自己境界拡張を変調する低速な整合層であり、機能力学パラメータ（Explore, Stabilize, Affiliate, Alert 等）およびその生物学的接続候補（DA, 5-HT, OXT, NA 等）によって計算・シミュレーション可能な力学モデルとして記述される。**
