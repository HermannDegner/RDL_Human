## ■ 2. RDL Core との接続

本モジュールは、RDL Core の最小動作フロー

$$
\text{EFP} \xrightarrow{M_B} F \to E \to H \xrightarrow{\theta} \text{Update}(M_B) \to M_B'
$$

における各変数を、次のように変調・拡張します：

- **$\text{EFP} \to F$ の解釈変調**: ノルアドレナリン（NA）による警戒バイアス
- **$E \to H$ の熱変換**: セロトニン（5-HT）による感度制御
- **$H$ の自発生成**: ドーパミン（D4）による退屈時の内部熱蓄積
- **$\theta$ の判定**: 局所閾値 $\theta_{\text{eff}}$ による Leap 制御
- **$B_{\text{self}}$ の拡張**: オキシトシン（OXT）による他者・集団の包摂
