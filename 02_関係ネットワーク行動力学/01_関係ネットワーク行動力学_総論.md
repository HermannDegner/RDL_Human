## ■ 0. 核心テーゼ（一文定義）

> **人間の行動および性格表現型とは、個体の内部に独立して存在する固定部品ではなく、肉体・道具・神経・他者・社会・履歴といった「関係ネットワーク（$W_{ij}$）」を、個体の $M_B^{\text{person}}$ が解釈（$\text{interp}$）して生成された認知空間（$\text{Space}_B$）の勾配場において、反復的に観測される「流向（Flow）」である。**

```text
関係そのもの（身体・道具・他者・制度・履歴）
      ↓
個体による解釈：interp(M_B^person, W_ij, EFP)
      ↓
解釈された認知空間：Interpreted Space_B（距離・障壁・勾配・到達可能域）
      ↓
流向：Flow（接近・回避・同期・維持・探索・迂回……）
      ↓ 反復観測
性格表現型：Observable Personality（「外向的」「慎重」「論理的」等）
```

## ■ 1. 生成アーキテクチャ（3層構造）

本体系では、行動および性格表現型が立ち現れる過程を以下の3層でモデル化する。

```mermaid
graph TD
    subgraph 関係ネットワーク行動力学の生成骨格
        L1["<b>【第1層：関係配置（Relational Configuration: W_ij）】</b><br>・肉体（骨格・筋力・代謝・疲労・回復力）<br>・道具（車・スマホ・AI・重機・武器）<br>・神経・生理状態（DA, 5-HT, OXT, NA, ホルモン）<br>・環境・他者・制度（周囲の強さ・力関係・法・社会的役割・過去の経験履歴）"]
        
        L2["<b>【第2層：解釈された認知空間（Interpreted Space_B）】</b><br>・個体 M_B^person による解釈：interp(M_B^person, W_ij)<br>・距離尺度・障壁（Barrier）・ポテンシャル勾配（Gradient）<br>・断崖（高危険・高コスト領域）・平坦路・窪地（安心・低コスト領域）"]
        
        L3["<b>【第3層：流向（Flow Dynamics）】</b><br>・局所的に低コスト／高引力な経路への偏り<br>・接近、回避、同期、維持、探索、攻撃、迂回などの動態"]
        
        P["<b>【観測表現型（Personality Phenotype）】</b><br>・特定観測境界 B から切り出された安定流向<br>・Big Five / MBTI / 社会的性格ラベル"]
    end

    L1 -->|interp(M_B^person, ...)| L2
    L2 -->|勾配に沿った流路選択| L3
    L3 -->|反復観測による圧縮| P

    L3 -.->|行動の反復・経験の蓄積| L1
    L2 -.->|学習による M_B^person の更新| L1
```

:::message
**【重要：解釈（interp）の介在】**  
同じ道具（車）、同じ他者、同じ法律であっても、誰にとっても同じ空間勾配（$\text{Space}_B$）になるわけではありません。個体の歴史的偏り（$M_B^{\text{person}}$）がそれをどのように解釈するかによって、立ち現れる空間形状と流向が分岐します。
:::

## ■ 2. 認知空間を変形させる主要要因群（Deformation Factors）

認知空間 $\text{Space}_B$ の形状（勾配・距離・障壁）は、以下の多様な要因の相互作用によって動的に変形します。

```text
Space_B deformation factors := {
    body,            # 肉体条件（体力、疲労、耐久性、感覚器特性）
    tool,            # 道具・テクノロジー（行為可能域、移動速度、出力）
    relationship,    # 対人関係（相手の強さ、信頼、力関係、敵意）
    social_position, # 社会的役割、立場、責任
    institution_law, # 制度、法律、明文化された規則
    language,        # 使用言語による境界形成習慣
    learned_history, # 個体史・成功体験・トラウマ
    current_state,   # 現在の生理・情動状態（覚醒度、空腹、ストレス）
    prediction,      # 認知距離 d ごとの予測解像度 R(d)
    threat_reward    # 危機重み w_threat / 目標重み w_goal / 新奇重み w_novel
}
```

## ■ 3. 有力な空間変形・流向仮説群

### 仮説 1：肉体的制約とコスト地形（Physical Constraints & Cost Landscape）
- **内容**: 肉体（第1層：物理構造）は、行動空間における移動・衝突・維持の**コスト地形を形成する基礎的な境界条件**である。
- **力学**:
  - 肉体の耐久性や回復力が高い場合、環境との物理的摩擦や衝突による損害リスクが低く見積もられやすい。
  - ただし、肉体が強靭であっても過去の危険経験（$M_B^{\text{person}}$）によって高警戒になることもあれば、非力な肉体でも安全な保護環境によって探索型になることもある。
  - すなわち、**「肉体的制約（Bio_bias） ⇄ 経験（Experience） ⇄ 学習（Learning） ⇄ $M_B^{\text{person}}$」**の循環として流向が定着する。

### 仮説 2：道具結合による行為可能域の変容（Tool Coupling & Affordance Shift）
- **内容**: 道具（車、スマホ、AIなど）との結合は、個体の**行為可能域（Affordance）、移動コスト、到達可能性を一瞬で書き換える**。
- **力学**:
  - 道具の装着によって $\text{Space}_B$ の局所地形（距離感や摩擦）が激変し、**「同じ個体から普段とは異なる別の流向が露出可能になる」**。
  - （例：車と結合した際、巨大な運動エネルギーをどう解釈するかによって、「攻撃的・短気な流向」が露出する個体もいれば、「より慎重な流向」が露出する個体も生じる。この分岐は $M_B^{\text{person}}$ が司る。）

### 仮説 3：場の相対剛性と境界調整の最適化（Relative Rigidity & Boundary Coordination）
- **内容**: 個体の振る舞いは、自分自身の絶対的性質ではなく、**他者・環境との相互作用コストのバランス**によって局所最適化される。
- **力学**:
  - 以下の条件が揃う場において、境界規則・予測・シグナル交換（礼儀・知性・協調）が発達しやすい：
    1. **相互破断コストが高い**（力任せの衝突が双方に大損害をもたらす）
    2. **反復接触がある**（一度きりの関係ではない）
    3. **逃走よりも関係維持の利益が高い**
  - これは「礼儀正しい性格」という固定属性を作らずとも、**なぜその場で礼節や調整行動が安定流向として選択されるか**を力学的に説明する。

## ■ 4. 既存性格モデル（Big Five / MBTI 等）の位置づけ

本体系において、Big Five や MBTI 等の既存心理学モデルは、**「人間を構成する独立した固定部品」**ではなく、

> **「同一の $M_B^{\text{person}}$ および $\text{Space}_B$ 上を流れる動的な Flow を、特定の観測境界 $B$ から切り出した圧縮断面（表現型）」**

として位置づけられます。

```text
                       M_B^person / Interpreted Space_B / Flow
                                       │
         ┌─────────────────────────────┼─────────────────────────────┐
         ↓                             ↓                             ↓
    【Big Five 断面】              【MBTI 断面】               【社会的ラベル断面】
    ・外部駆動性 (E)               ・情報結合様式 (T/F)          ・「論理的」「感情的」
    ・空間別慣性維持性 (C)         ・指向性 (E/I)                ・「社交的」「慎重」
    ・危機・熱反応性 (N)           ・知覚／判断枠組み (S/N, J/P)  ・「怒りっぽい」「大らか」
    ・境界可塑・探索性 (O)
    ・同期・協調性 (A)
```

## ■ 5. 心理学・行動科学理論の「受け皿」としての機能

関係ネットワーク行動力学の3層アーキテクチャは、既存の様々な心理学・社会学理論が**「どの層の現象を観測・記述しているのか」**をマッピングする共通の受け皿として機能します。

| 階層 | 主な理論・アプローチの対応例 |
| :--- | :--- |
| **第1層：関係配置** ($W_{ij}$) | 行動生態学、身体性認知科学、アフォーダンス理論、アクターネットワーク理論 (ANT)、社会環境論 |
| **第2層：解釈空間** ($\text{Space}_B$) | 場の理論 (Kurt Lewin)、認知地図、スキーマ理論、神経現象学、予測符号化理論 (Predictive Processing) |
| **第3層：流向** (Flow) | 力動精神医学、動機づけ理論、相互作用論、強化学習エージェント理論 |
| **観測表現型** (Phenotype) | 特性論 (Big Five)、タイプ論 (MBTI)、臨床診断基準 (DSM) |
