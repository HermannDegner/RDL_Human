## ■ 0. 一文定義

> **関係ネットワーク行動力学は、人間を孤立した固定属性の集合としてではなく、肉体・道具・神経・他者・社会といった重層的な関係ネットワーク（$W_{ij}$）を個体の $M_B^{\text{person}}$ が解釈（$\text{interp}$）して生成される実効拘束場（$C_B$）のコスト地形において、反復的に立ち現れる動的な流向（Flow）としてモデル化・解析する実践的骨格体系である。**
