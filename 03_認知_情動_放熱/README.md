## ■ 0. 一文定義

> **認知・情動・放熱（T3応用層）は、快、笑い、アハ体験、葛藤、時間感覚といった主観的・情動的体験を、個体の整合構造 $M_B$ における未回収関係 $\xi$ の蓄積、予測誤差 $E$ の解消、および内部熱 $H$ の放熱・相転移（Leap）プロセスとして定式化する力学体系である。**
