## ■ 0. 一文定義

> **関係ネットワーク行動力学（T2層）は、人間を孤立した固定属性の集合としてではなく、肉体・道具・神経・他者・社会といった重層的な関係ネットワーク（$W_{ij}$）の結節点において、多重の境界（$B$）が引く空間の勾配（Gradient）に沿って立ち現れる動的な流向（Flow）としてモデル化・解析する実践的力学体系である。**

## ■ 2. RDL Core / T1層との接続

- **T0（基盤層）**: 関係網 $W_{ij}$、境界 $B$、未回収関係 $\xi$、代謝フロー $EFP \to F \to E \to H \to \theta$
- **T1（基層構造・神経力学）**: 4層時間スケール（物理・基層・中核・上層）、神経パラメータ（DA, 5-HT, OXT, NA）
- **T2（関係ネットワーク行動力学）**: **【本層】** 身体・道具結合・場の相対剛性・多重境界勾配 $\to$ 行動・性格の生成
- **T3（社会・対話・生態系）**: 地域生態系調査プロトコル、対話による共同分解、制度設計
