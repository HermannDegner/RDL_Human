## ■ 0. 一文定義

> **対話・倫理・社会生態系（T3層）は、個体間の境界重ね合わせによる「共同分解（Co-decomposition）」、関係ネットワークの破断を防ぐ「動的倫理・教育放熱」、および人・仕事・ケアが循環する「地域局所生態系」の観測・統治プロトコルを統合する社会実装体系である。**
