## ■ 1. Big Five（五因子性格モデル：OCEAN）

### 従来理論の骨子
人間の性格は、外向性（E）、協調性（A）、誠実性（C）、神経症傾向（N）、開放性（O）の5つの独立した次元の組み合わせによって記述できる。

### RDLによる操作的再記述（SILNパラメータ分解）
特性論における因子は、実体的な「魂の属性」ではなく、**「特定の観測境界 $B_{\text{obs}}$ によって切り取られた、SILNの多次元流向（パラメータの偏り）の圧縮断面」** である。

```text
Extraversion (E: 外向性)      ≡  【外部駆動性】外界（人間・音・活動・タスク）への接近流向・探索重み
Agreeableness (A: 協調性)     ≡  【同期・結合性】他者状態への同期閾値 θ_sync の低さと関係維持（Affiliate）重み
Conscientiousness (C: 誠実性)  ≡  【空間別慣性維持性】遠距離目標 R(d_goal) の拘束力と境界保持力（P_hold）
Neuroticism (N: 神経症傾向)    ≡  【危機・熱反応性】危機予測 R(d_threat) の感度（Alert）と、誤差 E → 熱 H の変換率
Openness (O: 開放性)          ≡  【境界可塑・探索性】未確定領域 ξ への新奇重み（Explore）と境界引き直し（P_redraw）
```

## ■ 2. ユングのタイプ論 ＆ MBTI

### 従来理論の骨子
心の機能（思考・感情・感覚・直観）と態度の方向性（外向・内向）の組み合わせにより、16の性格類型を定義する。

### RDLによる操作的再記述（境界操作パラメータ）
MBTIの各軸は、**自己と世界の間に引かれた「境界 $B$ の操作特性と、予測解像度のピントの合わせ方」** として記述される。

```text
E / I (外向 / 内向)      ≡  主境界の所在：外部 W_ij との相互作用重視（E） vs 内部 M_B の整合重視（I）
S / N (感覚 / 直観)      ≡  予測解像度 R(d) の焦点：近距離高解像度 R(near) 重視（S） vs 遠距離・大域的パターンの低解像度外挿 R(far) 重視（N）
T / F (思考 / 感情)      ≡  状態分離性 vs 同期結合性：自他の状態分離（低同調）による論理処理（T） vs 低 θ_sync による情動の相互同期・同調（F）
J / P (判断 / 知覚)      ≡  境界操作特性：境界保持性 P_hold（早期収束・固定化・計画重視）（J） vs 境界可塑性 P_redraw（未確定 ξ の保持・臨機応変）（P）
```

## ■ 3. マーシャル・マクルーハン：メディア論（身体拡張論）

### 従来理論の骨子
メディア（道具や技術）は人間の身体・感覚器の「拡張（Extension）」である。「メディアはメッセージである」とし、道具そのものの性質が人間の認識構造を変容させるとした。

### RDLによる操作的再記述
```text
身体の拡張               ≡  個体の M_B と 外部の物理的道具 Tool が結合（Coupling）し、
                             新たな行為可能域と拘束空間 C_B を生成する状態
                             Space_B^coupled = interp(M_B, W_organism ⊕_κ Tool)
メディアはメッセージである ≡  対象（コンテンツ）だけでなく、道具（メディア）と結合したこと自体が
                             境界 B を変形させ、必然的に流向 Flow を変質させるという力学構造
ホット／クール・メディア  ≡  結合強度 κ、および未回収関係 ξ の補完にかかる認知負荷の差異
```

### 比較と接続
マクルーハンの直観は、RDL における **「装甲拡張型結合（車の乗車による境界拡張と攻撃性の露出）」** や **「境界融解型結合（スマホによる多重境界の液状化・放熱場の消失）」** といった道具結合力学として、より解像度の高い具体的な方程式（拘束度 $C$ と熱 $H$）へと翻訳される。
