## ■ 0. 目的と基本姿勢

本ディレクトリ群は、近代心理学・認知科学・精神医学・行動生態学・社会学が蓄積してきた代表的な既知理論を、**RDL（関係力学言語）の座標軸（基底量・時間スケール層）に沿ったツリー構造**として分類・マッピングする試みである。

:::message
**【注意：科学的統一ではなく、共通座標への配置】**  
本ツリーは「RDLが既存学問を科学的に説明・完全解明した」と主張するものではない。異なる切り出し境界（$B$）によって得られた各理論の知見を、**単一の力学言語（RDL）で相互比較・再検査可能にするための暫定的な翻訳マッピング（操作的再記述）**である。
:::

## ■ 1. ツリー構造の分類方針

既存学問を「分野別（心理学・経済学等）」ではなく、「RDLのどの力学変数・層に焦点を当てているか」でツリー化する。

| ツリー番号 | RDL側の対応力学 | 分類される主要な既存理論（例） |
| :--- | :--- | :--- |
| **01_神経_進化_発達系** | 4層時間スケール・下層優先則 | マズローの欲求階層、ピアジェの発達段階、進化心理学 |
| **02_空間_行動_環境系** | 実効拘束場 $C_B$ と勾配 $-\nabla C$ | レヴィンの場の理論、ギブソンのアフォーダンス、行動経済学 |
| **03_熱_誤差_情動系** | $EFP \to F \to E \to H \to \theta$ | フリストン（FEP）、フロイト（防衛機制）、アドラー（劣等感） |
| **04_性格_特性_身体系** | 道具結合 $\kappa$、SFO流向の表現型 | Big Five、MBTI、マクルーハン（メディア・身体拡張論） |
| **05_境界_愛着_社会系** | 多重境界 $B$、共同体、社会重力 | ボウルビィ（愛着理論）、マルクス（物象化・社会力学） |

## ■ 2. RDLによる理論横断マッピングの力学

```text
                               【人間動態の全体構造】
第1層：関係配置 W_ij       ─── [ギブソン / マクルーハン / ボウルビィ]
       ↓ interp(M_B, ...)
第2層：拘束空間 C_B        ─── [レヴィン / フリストンFEP / 行動経済学]
       ↓ 勾配に沿う流路
第3層：流向 Flow           ─── [マズロー / フロイト / アドラー / マルクス]
       ↓ 反復観測
観測表現型 Phenotype       ─── [Big Five / MBTI / 特性論]
```

既存の理論は「どれが正しくどれが間違っているか」ではなく、**人間動態という多層の関係力学系を「どの層から、どの境界 $B$ で切り取ったか」という観測断面の集合**として、RDLの共通座標上にすべて矛盾なくマッピングすることができる。
