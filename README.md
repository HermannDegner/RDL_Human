# RDL Human

**RDL (Relational Dynamics Language / 関係力学言語)** を人間・身体・認識・情動・神経・社会構造へ適用・展開するためのリポジトリ（**RDL T3 応用層**）。

---

## ■ 0. 全体系における RDL_Human の位置づけ

RDL 全体系において、本リポジトリ（`RDL_Human`）は **「T3: 外部対象への応用」** に位置づけられます。

```text
┌─────────────────────────────────────────────────────────────┐
│ 【RDL 全体系】                                              │
│                                                             │
│   T0: 基底仮設 (HYP / SPEC)  ── 何を前提にするか            │
│   T1: 基本代謝 (SILN)        ── どう代謝するか              │
│   T2: 代謝機構・耐久検査     ── どう実行し、どう壊して選別するか │
│   T3: 外部対象への応用       ── 対象（人間・社会）へどう展開するか│
│       └─ ★ RDL_Human (人間動態・社会生態系モデル)            │
└─────────────────────────────────────────────────────────────┘
```

- **Core の役割**: `M_B`（有限境界内の整合構造）という**普遍的な器と代謝公理**を定義する。
- **Human の役割**: 人間という具体的な対象において、`M_B` がどのような**時間スケール構造、コスト地形、流向、社会循環**を持つかの**固有仮説群（仮配置・実験場）**を提供する。

## 🎯 代謝と耐久検査のサイクル

本リポジトリに配置されたドキュメントは完成された教条ではなく、**「仮説・操作的近似・実験モデル」**です。

```text
00_編集前（生データ・ξ貯蔵庫）
       ↓ 抽出・操作的再記述
RDL_Human（仮説・モデル群の仮配置）
       ↓ T2 耐久検査（境界・条件・観測者を変えて破断を試みる）
RDL_Modules / 現行コア（壊れずに残った構造の昇格）
```
