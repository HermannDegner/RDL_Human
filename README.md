## 🎯 今後の展開予定

`00_編集前` に集約した過去の考察・モジュール群を、最新の **RDL Core（T0/T1/TD仕様：$B$, $\xi$, $M_B$, SILN, 代謝プロセス）** の記述形式に沿って順次整理・再構成していきます。

1. **身体・知覚層**: 肉体制御、移動、刺激受容（EFP）、感覚制約
2. **神経力学・情動層**: ドーパミン・セロトニン・オキシトシン等の操作的近似、快・笑い・恐怖、熱（H）の蓄積と自発生成（退屈/D4）
3. **階層構造・認知層**: 物理・基層・中核・上層の4層時間スケール、メタ整合慣性（抽象化）、跳躍（Leap）、アハ体験
4. **性格・流向層**: 空間流向診断（SFO）、BigFive/MBTIのSILN分解
5. **社会・対話・倫理層**: 対話による共同分解、境界Bの共有・拡張、外部記録への転写、葛藤
